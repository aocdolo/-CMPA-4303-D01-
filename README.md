# BrandBuild — Clothing Brand Marketing Guide

## What is this?

BrandBuild is a digital resource hub designed for new and small clothing-brand owners who want to improve the way they market their businesses online.

The website provides useful information and strategies about social media marketing, website design, branding, product photography, and digital advertising.

BrandBuild also includes an interactive marketing resource filter that allows visitors to select a category and quickly find information related to what they need.

## Why does it exist?

Starting and growing a clothing brand can be difficult, especially for new business owners who are still learning how to market their products online.

Marketing information is often spread across social media, videos, websites, and other platforms. BrandBuild was created to organize useful information in one place and make it easier for clothing-brand owners to learn marketing strategies they can apply to their businesses.

The goal of BrandBuild is to make clothing-brand marketing information simple, organized, and easy to access.

## Interactive Feature

For Project 01, I added a **filterable Marketing Resource Guide**.

Users can filter the website's marketing resources by:

- All
- Social Media
- Websites
- Branding
- Photography
- Advertising

When a user selects a category, JavaScript automatically hides resources from the other categories and displays the information related to the selected topic.

I chose this feature because it serves a useful purpose for the website. Instead of scrolling through every marketing resource, clothing-brand owners can quickly find the type of information they are looking for.

The feature was designed to work on desktop, tablet, and mobile screen sizes.

## What tools did I use?

### HTML

I used HTML to create the structure and content of the website, including the navigation, marketing resources, filter buttons, and resource cards.

I used CSS to control the colors, typography, spacing, layout, resource cards, buttons, and responsive design. Media queries were used to make the website adapt to smaller screens.

### JavaScript

I used JavaScript to create the interactive resource filtering feature. JavaScript detects which category button the user selects and updates the resources displayed on the page.
